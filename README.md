# Personal Finance Tracker

## Overview
Personal Finance Tracker is a web-based application developed to help users manage their daily financial activities efficiently. The system allows users to track income, expenses, and spending categories in one centralized dashboard.

The goal of this project is to simplify personal budgeting and provide users with better visibility into their financial habits.

---

## Features

- Add and manage income records
- Add and track expenses
- Categorize transactions
- Monthly financial summaries
- Dashboard for expense monitoring
- User-friendly interface
- Transaction history management
